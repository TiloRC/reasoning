  not pushed); the default path is behaviorally unchanged

  removing the private `_known_template` cross-import by sharing one template

  `sympy.assumptions.ask_generated`. The 81 number and 24 matrix clauses are

## 7. Risks and open items

1. **Pin drift.** `test_knownfacts.py` and `regen_known_facts.py --check`
   catch drift while the pinned SymPy is installed, but a SymPy-free
   environment serves the table as-is. Bumping the pin requires rerunning the
   tool and committing the diff.
2. **Merged re-indexing.** `knownfacts.template` re-encodes clauses when both
   families are selected. Semantics are order-independent and were diffed
   against the old path; model counts (`[64]`, `[400]`, `[64, 400]`) are
   unchanged.
3. **Boundary set is opt-in by convention.** A new core module must be added
   to the Phase 0 test to be covered; the README lists the intended split.
4. **Repo-root `sympy/` tree.** The repository tracks a partial SymPy source
   subset at `sympy/`; because it has no top-level `__init__.py` it acts as a
   namespace package when the repo root is on `sys.path` and no regular
   SymPy is installed. The guard blocks by name, so the test is unaffected,
   but scripts that put the repo root on `PYTHONPATH` can see that namespace
   instead of a missing `sympy`.
5. **`KnownTemplate` no longer exposes the `(numbers, matrices)` flags.**
   Nothing needed them after the refactor; the tests identify the selection
   through the predicate list and model counts.
